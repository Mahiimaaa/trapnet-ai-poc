# TrapNet AI – PoC

## Project
TrapNet AI: Deception-Driven IoT Security Appliance

## Team
CyberHive (Individual Participant)

## Description
This proof-of-concept demonstrates an autonomous agent-based IoT security system that:
- Discovers IoT devices
- Profiles risk levels
- Redirects attackers to honeypots
- Executes autonomous response actions

## How to Run
Run these commands in order:

python device_discovery.py  
python risk_scoring.py  
python deception_engine.py  
python response_agent.py  

## Tech Stack
Python, Agentic AI Logic, IoT Security, Deception Techniques
